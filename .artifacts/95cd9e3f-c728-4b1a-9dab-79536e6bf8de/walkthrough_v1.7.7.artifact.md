# Neo Play TV v1.7.7 Release Hesabatı

Bu versiyada Türkiyə radiolarının siyahıda görünməsi ilə bağlı texniki problem kökündən həll edildi.

## Yeniliklər və Təkmilləşdirmələr

### 1. Dəqiq Ölkə Axtarışı (ISO Codes)
- **Təsvir**: Radio Browser API-də ölkə adları (məs: "Turkey") bəzən server tərəfindən yanlış interpretasiya oluna bilirdi.
- **Həll**: İndi tətbiq beynəlxalq ISO ölkə kodlarından (**AZ** və **TR**) istifadə edərək birbaşa nöqtə-atışı axtarış edir. Bu, Türkiyə radiolarının 100% dəqiqliklə siyahıya gəlməsini təmin edir.

### 2. Ardıcıl Yükləmə Stabilliyi
- Azərbaycan və Türkiyə radiolarının yüklənmə prosesi optimallaşdırıldı. İlk olaraq yerli radiolar, ardınca isə dərhal Türkiyə stansiyaları siyahıya əlavə olunur.

- **Versiya**: 1.7.7 (60)

- **Status**: Build finished successfully.
