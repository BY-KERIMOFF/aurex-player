# Neo Play TV v1.7.1 Release Hesabatı

Bu versiyada tətbiqə tamamilə yeni, avtomatik işləyən və ana ekranda xüsusi yeri olan "RADİO" bölməsi əlavə edildi.

## Yeniliklər və Təkmilləşdirmələr

### 1. Yeni "RADİO" Bölməsi (Geniş Dizayn)
- **Ana Ekran İnteqrasiyası**: Radio bölməsi artıq digər kartların yanında deyil, ana ekranda tamamilə ayrı və geniş bir sətir kimi yerləşdirildi. Bu, bölmənin daha asan tapılmasını və daha peşəkar görünməsini təmin edir.
- **Avtomatik Stansiya Axtarışı**: Radio Browser API vasitəsilə Azərbaycanın yerli radioları və dünyanın ən populyar stansiyaları avtomatik tapılır və siyahılanır.
- **Xüsusi Pleyer Dizaynı**: Radio dinləyərkən loqo animasiyası (pulse) və musiqi temalı dizayn tətbiq edildi.

### 2. Texniki Təfərrüatlar
- **ExoPlayer İnteqrasiyası**: Radio yayımları üçün optimallaşdırılmış ExoPlayer konfiqurasiyası quruldu.
- **Avtomatik Fallback**: Yerli radiolar tapılmadıqda sistem avtomatik olaraq qlobal Top-50 siyahısını yükləyir.
